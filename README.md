# QuickSort

Последовательная (`Seq`) и параллельная (`Par`) реализации QuickSort для срезов упорядоченных типов.

## Запуск

```bash
go test ./...
go test -race ./...
go run ./cmd/bench
```

Бенчмарк сортирует 100 млн случайных чисел, выполняет 5 запусков и сравнивает `Seq` при `GOMAXPROCS(1)` с `Par` при `GOMAXPROCS(4)`.

Для меньшего объёма данных:

```bash
go run ./cmd/bench -n 1000000 -runs 3
```
